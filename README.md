# تحميل برنامج WhatsApp Group Manager للويندوز

[⬇️ اضغط هنا للتحميل](https://github.com/mohamedomar00700-sudo/whatsapp-group-manager/raw/download/WhatsAppGroupManager-Windows.zip)

1. فك الضغط عن الملف.
2. دبل كليك على **WhatsAppGroupManager.exe**.
3. لو ظهرت رسالة زرقا *Windows protected your PC*: دوس **More info** ثم **Run anyway** (مرة واحدة بس).
4. هيفتح المتصفح لوحده، امسح رمز QR من موبايلك: واتساب ← الأجهزة المرتبطة ← ربط جهاز.
5. خلي النافذة السودا مفتوحة طول ما انت شغال.

جلسة الواتساب بتتحفظ على جهازك انت بس.
