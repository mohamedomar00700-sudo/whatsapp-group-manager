# WhatsApp Bulk Group Member Remover Pro 🚀
### مدير مجموعات واتساب - الحذف الجماعي الذكي والآمن

تطبيق ويب محلي (Local Web Dashboard) متكامل وسهل الاستخدام لإدارة وحذف أعضاء مجموعات واتساب دفعة واحدة بأمان تام وبدون حظر الحساب، مع دعم كامل للغة العربية.

---

## ✨ المميزات الرئيسية (Key Features)

- **📲 ربط فوري وآمن بالواتساب (QR Code):**
  - يدعم بروتوكول WhatsApp Multi-Device عبر مكتبة Baileys.
  - حفظ الجلسة محلياً على جهازك بأمان تام دون الحاجة لمسح الرمز في كل مرة.

- **📊 خيارات إدخال متعددة ومرنة:**
  1. **ملف إكسيل (Excel / CSV):** قراءة الشيتات والتعرف التلقائي على عمود رقم الهاتف والاسم.
  2. **نسخ ولصق نصوص (Copy/Paste):** استخراج ذكي لجميع الأرقام من أي نص ملصق.
  3. **التعرف الضوئي من الصور (Image OCR):** قراءة واستخراج الأرقام من الصور ولقطات الشاشة (يدعم لصق الصور مباشرة بـ `Ctrl+V`).
  4. **التحديد اليدوي المباشر:** تصفح جميع أعضاء المجموعات المحددة واختيار من ترغب بحذفه بنقرة زر بدون شيت.

- **🛡️ نظام الحماية من الحظر (Anti-Ban Safety Engine):**
  - فواصل زمنية مدروسة بين كل عملية حذف مع تباين عشوائي (Random Jitter).
  - استراحة أمان تلقائية بعد كل دفعة عمليات.
  - أزرار تحكم كاملة: إيقاف مؤقت (Pause)، استئناف (Resume)، وإيقاف نهائي (Stop).
  - حماية المشرفين (Admins) تلقائياً واستثناؤهم من الحذف غير المقصود.

- **⚡ لوحة تحكم عصرية (Modern Arabic/English UI):**
  - شريط تقدم مئوي وحي.
  - شاشة سجلات حية (Live Terminal Logs).
  - تصدير تقرير نهائي بملف إكسيل يوضح نتائج كل عملية.

## 🛠️ متطلبات التشغيل (Prerequisites)

- **Node.js** (الإصدار 18 أو أحدث)
- متصفح ويب حديث (Google Chrome, Microsoft Edge, Firefox)

## 🚀 التثبيت والتشغيل (Getting Started)

1. **استنساخ المستودع (Clone Repository):**
   ```bash
   git clone https://github.com/YOUR_USERNAME/whatsapp-group-manager.git
   cd whatsapp-group-manager
   ```

2. **تثبيت الاعتماديات (Install Dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل التطبيق (Start Application):**
   ```bash
   npm start
   ```
   أو على نظام ويندوز بالنقر المزدوج على ملف:
   ```text
   start.bat
   ```

4. **فتح التطبيق في المتصفح:**
   افتح الرابط التالي:
   ```text
   http://localhost:3000
   ```

## 🔒 الأمان والخصوصية (Privacy & Security)

- جميع البيانات، وجلسات الاتصال المشفرة، وأرقام الهواتف تعمل وتُخزن **محلياً على جهازك فقط (100% Localhost)**.
- لا يتم إرسال أي بيانات أو جلسات إلى أي خوادم خارجية.
- ملفات الاعتماديات والجلسات مشمولة في `.gitignore` لمنع رفعها إلى GitHub.
